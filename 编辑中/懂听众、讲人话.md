## 1. 前言

人和人之间是需要交流的，听明白话、说明白事，我始终认为是一个非常重要的能力，是一个人逻辑思维最直观的表现。在职场环境中尤为重要，建立沟通关系更是高阶能力，尤其对于不同角色之间，是减少阻力、事半功倍的重要技巧。

本文是想，让看这篇文章的人，或多或少都掌握其中的技巧，这就是本文的目的。这篇文章想写已经很久了，总觉着差点意思。但最近写东西换了个视角，常讲常新吧。重心放在**“职业表达”**上，私下follow 自己风格就好。

本文会涉及到：如何回归“讲人话”、如何去“懂听众” 的表达技巧，同时会带来一些写作技巧、演讲技巧 等硬技能，野路子，不喜就喷。

## 2. 表达技巧：讲人话、懂听众

### 2.1 你要说些什么？

表达总归会有**「目的」**，在开口、动笔之前，至少要知道自己想说些什么，抛开一切技巧、结构、思路，先想想“自己想表达什么？”、“想达成什么目的”。

这一步是前置让自己聚焦，是后面所有动作的前提。如果还是抓不住重点，就HighLight 出来，始终盯着目标去做讲述，同时把这个告诉听众。

```
// 这部分信息并不重要，做个大概参考
1. 晋升/面试答辩，是想借事表达自己的能力模型，让评委认可；
2. 成果汇报，是想表达“这事儿牛逼且清晰”，让老板认可；
3. 方案汇报，是想表达“高价值要资源、方法方案合理”，让老板给资源；
4. 协同沟通，是要表达协同边界、价值共享、你需要干点什么，让协同方好好配合；
5. 方案评审，是要表达方案清晰、合理、可执行、无风险，让事儿有据可依；
6. 进展汇报，是要表达当下的状态、离终点的距离、机会/卡点，让信息对齐、风险解除；
7. 等等
```

在你下次想找人表达的时候、需要你去表达的时候，先想想是哪种类型（不用强行分类），你要说些什么、想达成什么目的。**如果沟通没有明确目的，就把嘴闭上**

### 2.2 要有逻辑：项目、思路、框架

不同的场景、不同的目的，写出来的东西是不一样的。比如说晋升，为了表达不同的能力模型，写出的东西就不一样，低职级，事儿也相对容易讲，就最简单的方式写出来，降低信息获取难度；事儿如果不容易讲，就是循序渐进的讲故事。

无论哪种方式，抓好三个关键词：**项目、思路、框架**，因地制宜的去做对应的处置，不要套模版、不要套模版、不要套模版。

第一点：**项目要有体感**

要想讲的东西有体感，关键是**把项目立起来**，通俗的比喻是“让对方看到要打的怪兽是什么”，各种技巧中的背景构建、冲突构建、立意表达，本质上都是这个事儿，一定要围绕项目、围绕问题去讲事情，这东西可以粗暴的理解为**一个看得见、摸得着、有体感的话题**。

第二点：**思路要清晰简单**

思路是整个逻辑表达的核心，要把事儿**完整的**说明白，“今天我讲两个事儿”、“从XXX到XXX”、“定义、解构、剖析”、“方法研讨、迁移分析”，甚至“流水账平铺” 都是可以用的方式。最主要是你讲的东西，要能托得住前面的项目，解得掉问题，最好一听上去就是合理的。

**其中你要以什么表述，让对方获得什么信息，要以什么事，让对方更有体感，要以什么观点，让对方认可且接纳**，这些在大思路中的插空才是核心，是需要你重点关注的东西。

第三点：**框架要有结构**

你要讲的事情，最好是要有结构的，让听众、读者，循序渐进的接受信息，无论是背景-冲突-解决，还是机会-方法-收益，只要有表达框架就行，这个框架决定了的表达，是结构化的、是信息完整的。

总之能把事儿说明白就好，只要不为了“高大上/我很懂/优越感”，在半空讲一些：**高大上无落地的方法论、信息不对等的描述、时高时低的表述、无关紧要的细节自嗨、对着门外汉讲技术、对着专业讲废话、云里雾里的先放个超大信息图、逻辑不自洽的牛逼**。

顶多算是表达功底不到家，还都算是在讲人话，不知道怎么讲的时候，就最朴素的方式，用大白话把原委说出来。

### 2.3 结构化：star、金字塔、scqa、5w1h、mece 但“无招” 更重要

所有的技巧几乎前期都是有用的，中期白搭，后期融会贯通。

这些表达技巧附赠了很多种具体的，使用场景或者case，但大多数人，要么写的时候忘了，要么生搬硬套，这些技巧的作用收效甚微。

从我的个人经历、对同学们的观察来看，**对一窍不通的新人来说，起到一个照葫芦画瓢的作用，这点我觉着就挺好了**。新同学，可以查一下这些关键词儿（star、金字塔、scqa、5w1h、mece），多多少少入个门。

对于表达有一点技巧的同学，这些招数，反而是限制大家发挥的、限制大家表达能力成长的阻力。最好的方式，这些技巧应该像“盲打”一样，很自然就能从笔下出来的东西。

如果已经写了一年以上的、10篇以上的东西了，不妨忘掉这些技巧。按照你的思路去写东西，返璞归真：“目的、原因1、2、3” 说清楚，中间的跌宕起伏、叙事结构，由语言能力、逻辑思维把控就好，写的多了，你就发现你也能总结出类似于 scqa 之类的讲述技巧。

总之，早日融会贯通。

### 2.4 双刃剑：观点、判断、认知、方法论

首先，这些东西用不好，不要乱用，其次也并不好用，尽管前些年我很热衷。

大家应该看过很过东西，里面的观点、判断、认知、方法论，无比的清晰，甚至有种画龙点睛的作用，有的读者看完，会觉着“他该做成这个事儿”。

这东西是个双刃剑，如果你的观点、判断、认知、方法论，是新颖、有深度、易接受的，是可以适度使用的，这些东西**“贵精、不贵多”**，而且极度依赖于个人的总结和判断力。如果是刚工作几年的小朋友，离这些“脏东西”远一些，务实一些更重要。

如果工作5年以上，应该需要具备这些能力了：主动判断、观点假设、认知提炼、方法总结，试着在自己的表达里加入这些东西，确实会起到帮助软素质成长的作用，你老板反正早已经听麻了，除非足够自信。

### 2.5 懂听众的表达技巧

事情本身容易讲，那就最简单的方式晒出来，刺激感官。有的事不容易讲，就需要循序渐进的“讲故事”，拉注意力。

如果事儿本身不容易讲，我们写作的重心应该更倾向于听众是谁？**讲人话是基础，懂听众才是进阶**。这里指的是“泛听众”，指的是特定环境、特定时间、特定角色、特定人的听众。

**信息对程度**

首先是信息的对称度问题，要正视信息的对称度，哪怕你认为 “这不是常识吗？”，该补充的背景信息、上下文信息一点都不能少，就算信息完全对称，也要有上下文的“召回机制”。

还有种情况是，反向不对称，你讲的东西，你知道的上下文更少，**那就抓重点、聊特例**。

**换位审视**

其次，知道听众是谁也非常重要，最近刚吸收了哪些信息、当天接受的信息密度如何、心情好坏都是该考虑的因素，以此来微调个人表达的**时机、方式**

最好是，“如果我是他”、“我知道他想要什么”，我看到这些信息是什么反应？我能get 到多少。

**聚焦对方注意力**

不同的角色，关注问题、关注点都是不同的，比如+1、+2、协同方、广大分享受众，差异贼大。多思考一下，什么角色、什么位置、什么层级，他们注意力在哪，一种好用的方式是 **“让他们做点什么”**

## 3. 关于 “回答”

你做完表达，或者别人做完表达、你听完，肯定是要“做一些交流的”，比如晋升这种场子，还会有严肃的QA 环节。

对于表达后的回答类沟通，本质上是一种信息的补全，无论讲的多完美，总会有照顾不到的地方，也不可能100%懂听众，还有些时候需要QA 做**二次补充、说服**，这时候就需要利用好回答了。

### 3.1 信息充分交流才能补全

要听懂问题再回答，提问者天然的就不可能非常懂，这种信息不对等是客观事实。所以，学会**确认问题**，然后针对问题充分的交流，这样才能更好的去补全信息。

知乎名言：先聊是不是，再聊为什么。

### 3.2 回答技巧

回答的是问题、针对的是事实，不是对人，尤其是前面提到的晋升场子。

所有提问题者，在心理层面，几乎都会希望收到一个“肯定”，这是人的下意识找赞同者的潜意识。但这个“肯定”的来源并不重要，避免一个误区，不要对人表达态度（**不挑战权威、不盲从权威、不对人做评价**）、也不要对结论表达态度，不要急着赞同、否定、反驳。

你要做的是：**对问题本身表达肯定，这是个好问题，甚至做提问引导。然后要辩证的对待问题结论，以平等讨论的视角去做回答，对于结论：“是这样的，然后辩证的正反都看看，基于场景给出自己的观点就好”。**

其次，回答的结构化也非常重要，观点、原因：1、2、3；听众会更容易接纳一些，**开头总结、结束再总结，更不容出错**。

### 3.3 预设问题

预埋问题的场子，一般都是晋升答辩、项目立项、面试沟通，这样说服的场子。这些时候，是需要一定程度上预设问题的，故意挖个坑等人问，答案要提前准备，别挖坑埋自己。

说服的场子里，提出疑问-得到回答或者被说服，很多时候，甚至比信息直接接纳要强的多，会更有记忆点。

### 3.4 回答怎么练？

这是一个很实际的话题，就用锻炼思辨能力的经典方法，自己定义50个问题，不要准备答案，然后做即时回答训练，针对特定场景很快就能练出来。

## 4. 一点演讲技巧

面对材料的讲述过程，这里姑且称之为“演讲”。

### 4.1 演讲参照物？

大多数时候，前面产出的材料，仅仅只是一个参照物，用于你口述表达的参照物，**照着材料读一定是不可行的。** 纯阅读、纯听、边看边听，演讲内容、技巧、材料是完全不同的。

doc 适合纯阅读的场景、PPT 适合边看边听的场景、你的仅口述和肢体语言适合纯听，至少在职场里大致是这样。很多时候，doc 也会被用来作为边看边听的参照物，没关系，降低信息密集度，ppt 式doc 是这个互联网太常见的东西了。

你的参照物，要复合人类的习惯：从左到右、从上到下、别切太多块、密度要低。

### 4.2 演讲的具体技巧？

大点声不是坏处、带点情绪、抑扬顿挫、多一点肢体语言，这些是最基础的方式，下面给大家带来一些更好用的方法，很多方法都是利用了人脑的信息接受习惯：**“大脑就是被设计成这样”**

#### 4.2.1 多讲故事，少讲道理

大脑记不住抽象道理，但记得住故事。故事自带人物、冲突、画面。罗永浩讲手机，讲的是“我们去找供应商被拒”“一个细节改了七版”。你说“我们要重视用户体验”，不如讲一个用户骂娘、老板骂人的具体案例。

#### 4.2.2 在恰当的时机，讲个笑话

大脑对带情绪的事件记忆更牢，幽默还能降低防御。老罗的演讲里平均几分钟就有一个段子或自嘲，我曾经听过的一些好的汇报现场，氛围往往是轻松的，不是为了搞笑，是把注意力攥在手里。

#### 4.2.3 金句记忆点

一次演讲、一次演讲，说白了能被记住的信息是在太少了、非常非常有限，而且你也不是在教书。你需要影响的是那30分钟、那60分钟内听众的反应和判断。

那就把精力放在搞定那几十分钟身上。然后建立正向的金句记忆点就好了，回忆起来，能想起那个慷慨激昂的你，和那些金句瞬间，就赢了。

#### 4.2.4 具体化、数字化、对比化

大脑对“具体名词+数字+对比”最敏感。虽然雷总现在处境很难，但不要否认雷总的技巧，“薄”不如“比硬币还薄”，“快”不如“比上一代快 40%”，还有乔总“ipod能让你口袋装下多少首歌”，之前一个演讲课的老师总提这个例子。虽然不是精确数字，但具体形象。

#### 4.2.4 开头、结尾

开头、结尾非常重要，练不好全程，就练好开头和结尾。

## 5. 写在最后

现在AI 来了，信息量只会越来越高，信息密度越来越低，仍然大量的人持续AI 注水，不逊色于当年的CSDN。有两个误区：

第一，大家利用好AI，不是用AI 以量取胜，**信息越多、信息越少；信息越杂、信息越少；信息越乱、信息越少**；

第二，利用好AI，不是要加一些“润”词儿，大白话比AI 风朴实的多；

你会发现之前表达能力强的人，有AI 只会更犀利，表达能力弱的，有AI 只会更糙，苦练基本功吧：听、说、读、写、思，其次可以琢磨一下个人的“写作、演讲风格”。

还有，倾听、表达这个事儿，和内向/外向没什么关系，内向不是不擅长表达，外向也不是擅长沟通，非要说有关系，顶多就是一定程度可能决定了你练习的多少而已，别把不善言辞与性格划等号。

先写这么多，关于一些具体场合的沟通、表达，比如说谈判技巧，后面找机会放在协同里聊吧。

跟厨师尝菜一样，自己写完的东西、自己讲的东西，自己尝尝。
